# F. Dr.Z, the Raider

- 时间限制：3 秒
- 内存限制：256 MB

## 题目描述

Dr. Z 准备在 Minecraft 中进行一次大规模突袭，这次目标是 `n` 个村庄。村庄之间由 `n−1` 条道路连接，任意两个村庄都可互相到达。Dr. Z 只沿这些道路移动。第 `i` 条道路连接村庄 `u_i` 和 `v_i`，权值为 `w_i`。

为了收集所有村庄的资源，Dr. Z 选择一个 `1..n` 的排列 `p_1, p_2, …, p_n`，并按此顺序访问每个村庄恰好一次：先收集 `p_1` 号村庄的资源，然后沿经过道路数最少的路径前往 `p_2` 号村庄并收集资源，再依次前往后续村庄。

从村庄 `x` 移动到村庄 `y` 的代价定义为最短道路路径上所有道路权值的按位异或值。也就是说，如果路径经过道路 `e_1, e_2, …, e_k`，则 `cost(x,y) = w_{e_1} ⊕ w_{e_2} ⊕ … ⊕ w_{e_k}`。排列 `p` 对应突袭的总成本为：

`f(p_1, p_2, …, p_n) = Σ cost(p_i, p_{i+1})`，其中 `1 ≤ i < n`。

对于所有 `1..n` 的排列，求它们对应的总成本之和。答案对 `998244353` 取模。

## 输入格式

第一行包含一个正整数 `n`（`2 ≤ n ≤ 2 × 10^5`）。

接下来 `n−1` 行，每行包含三个非负整数 `u_i, v_i, w_i`，表示一条道路连接村庄 `u_i` 和 `v_i`，权值为 `w_i`（`1 ≤ u_i, v_i ≤ n`，`0 ≤ w_i < 2^30`）。

## 输出格式

输出一个整数，表示答案。

## 样例

**输入：**

```text
5
1 2 1
1 3 2
2 4 3
2 5 4
```

**输出：**

```text
1632
```

## 说明

例如，令 `p_1=1, p_2=2, p_3=3, p_4=4, p_5=5`。则：

- `cost(1,2) = w_1 = 1`；
- `cost(2,3) = w_1 ⊕ w_2 = 1 ⊕ 2 = 3`；
- `cost(3,4) = w_2 ⊕ w_1 ⊕ w_3 = 2 ⊕ 1 ⊕ 3 = 0`；
- `cost(4,5) = w_3 ⊕ w_4 = 3 ⊕ 4 = 7`。

因此该排列的总成本为 `1 + 3 + 0 + 7 = 11`。按位异或逐位比较两个数：对应位不同时结果为 `1`，相同时结果为 `0`。
