# D. Exchange Courses

- 时间限制：1 秒
- 内存限制：256 MB

## 题目描述

新学期开始，又到了选课的时候。学生 A 选上了课程 `a`，但没有选上自己想要的课程 `b`。另外有 `n` 名学生也对已选课程不满意，于是他们决定相互交换课程。

如果学生 A 和学生 B 分别选了课程 `A` 和 `B`，交换后两人分别选课程 `B` 和 `A`。除学生 A 外，每名学生只愿意换成自己指定的目标课程，不接受其他课程。学生 A 第一次交换时不要求直接得到目标课程。

请判断学生 A 能否通过交换得到课程 `b`；如果可以，求所需交换次数的最小值。除学生 A 外，有 `n` 名想要交换课程的学生。

## 输入格式

第一行包含一个正整数 `n`（`1 ≤ n ≤ 10^5`），表示除学生 A 外参与交换的学生数。

接下来 `n` 行，每行包含两个字符串 `s_i` 和 `t_i`，表示第 `i` 名学生当前选了课程 `s_i`，并希望换成课程 `t_i`。

最后一行包含两个字符串 `a` 和 `b`，表示学生 A 当前选了课程 `a`，希望换成课程 `b`。

额外约束：`|a|, |b|, Σ(|s_i| + |t_i|) ≤ 10^6`；对所有 `i`，`s_i ≠ t_i`，且 `a ≠ b`。所有课程名称仅由大小写英文字母和数字组成，不含其他特殊字符。

## 输出格式

输出一行，表示最少交换次数。如果无法得到目标课程，输出 `-1`。

## 样例 1

**输入：**

```text
3
math English
Chinese math
Biology Chinese
math Biology
```

**输出：**

```text
2
```

## 样例 2

**输入：**

```text
3
math English
Chinese math
Biology Chinese
Biology math
```

**输出：**

```text
-1
```

## 说明

对于第一个样例，学生 A 可以先与第二名学生交换，得到 `Chinese`；再与第三名学生交换，得到目标课程 `Biology`。共交换两次，并且可以证明这是最少次数。
