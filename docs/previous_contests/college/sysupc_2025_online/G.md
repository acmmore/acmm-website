# G. Dr.Z’s Trial

- 时间限制：1 秒
- 内存限制：256 MB

## 题目描述

Dr. Z 正在参加一场试炼。面前最初有一组数 `v_1, v_2, …, v_n`。Dr. Z 可以选择一个非负整数 `m`，然后与试炼系统进行 `m` 轮对抗。每轮中：

1. Dr. Z 从当前数集中选择两个不同的数 `a` 和 `b`，并选择 `c ∈ {0,1}`。
2. 若 `c=0`，系统计算 `d = a & b`；若 `c=1`，系统计算 `d = a ⊕ b`。其中 `&` 表示按位与，`⊕` 表示按位异或。
3. 如果 `d` 尚未出现在数集中，就将它加入数集。

完成所有轮次后，数集中的最大值就是 Dr. Z 的分数。他希望分数尽可能高，同时尽量少进行对抗。请你求出可能达到的最高分 `s`，并给出一个不超过 3000 轮的策略，使最终分数为 `s`。

如果分数可以无限大，或者无法在不超过 3000 轮内达到最高分 `s`，需要相应说明。

## 输入格式

第一行包含一个整数 `T`（`1 ≤ T ≤ 10^3`），表示测试用例数。对于每个测试用例：

- 第一行包含一个整数 `n`（`1 ≤ n ≤ 5 × 10^5`）。
- 第二行包含 `n` 个互不相同的非负整数 `v_i`（`0 ≤ v_i < 2^30`）。

保证所有测试用例的 `n` 之和不超过 `5 × 10^5`。

## 输出格式

对于每个测试用例：

- 如果分数可以无限大，输出一行 `infinite score`，然后处理下一个测试用例。否则，先输出最高分 `s`。
- 如果无法通过不超过 3000 轮达到 `s`，再输出一行 `no way to end early`，然后处理下一个测试用例。
- 否则，输出策略：先输出轮数 `m`（`0 ≤ m ≤ 3000`），再输出 `m` 行，每行包含三个非负整数 `a_i, b_i, c_i`（`a_i ≠ b_i`，`c_i ∈ {0,1}`），表示本轮选择的两个数和操作。每轮开始时，`a_i` 和 `b_i` 都必须已在数集中。

## 样例

**输入：**

```text
2
4
3 1 2 4
3
2 0 1
```

**输出：**

```text
7
4
1 2 1
3 4 0
4 3 1
2 0 1
3
1
1 2 1
```

## 说明

第一个测试用例中，可以用以下操作达到最高分 `7`：

1. 选择 `a=1, b=2, c=1`，得到 `1 ⊕ 2 = 3`。数集中已有 `3`，因此不会重复加入。
2. 选择 `a=3, b=4, c=0`，得到 `3 & 4 = 0`，将 `0` 加入数集。
3. 选择 `a=4, b=3, c=1`，得到 `4 ⊕ 3 = 7`，将 `7` 加入数集。
4. 选择 `a=2, b=0, c=1`，得到 `2 ⊕ 0 = 2`。数集中已有 `2`，因此不会重复加入。

最终数集中数的最大值为 `7`，且可以证明无法得到更大的分数。

按位与逐位比较两个数：仅当对应位都为 `1` 时结果位为 `1`，否则为 `0`。按位异或在对应位不同时结果为 `1`，相同时为 `0`。
