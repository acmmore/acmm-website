# C. triangle

- 时间限制：1 秒
- 内存限制：256 MB

## 题目描述

Dr. Z 喜欢三角形。他得到一个长度为 `n` 的序列 `l`。请统计满足条件的三元组 `(i, j, k)` 的数量，其中 `1 ≤ i < j < k ≤ n`，并且：

- `l_i + l_j > 0`、`l_j + l_k > 0`、`l_i + l_k > 0`；
- 存在一个三角形，其三条边长分别为 `l_i + l_j`、`l_j + l_k` 和 `l_i + l_k`。

## 输入格式

第一行包含一个整数 `n`（`3 ≤ n ≤ 10^6`），表示序列长度。

第二行包含 `n` 个整数 `l_i`（`-10^9 ≤ l_i ≤ 10^9`）。

## 输出格式

输出一个整数，表示满足条件的三元组数量。

## 样例 1

**输入：**

```text
5
-2 4 4 -1 0
```

**输出：**

```text
0
```

## 样例 2

**输入：**

```text
4
1 3 5 -10
```

**输出：**

```text
1
```
