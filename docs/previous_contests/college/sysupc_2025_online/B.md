# B. candy

- 时间限制：0.5 秒
- 内存限制：256 MB

## 题目描述

Dr. Z 喜欢吃糖果。一天，他得到了一排 `n` 颗糖果，每颗糖果有一个甜度值 `a_i`。Little Z 只能吃一段连续的糖果，并且为避免蛀牙，所吃糖果的甜度总和不能超过 `m`。请你求出他最多能吃多少颗糖果。

## 输入格式

第一行包含两个整数 `n, m`（`1 ≤ n ≤ 200000`，`0 ≤ m ≤ 10^9`），分别表示糖果数量和允许的最大甜度总和。

第二行包含 `n` 个整数 `a_i`（`0 ≤ a_i ≤ 10^9`），表示第 `i` 颗糖果的甜度。

## 输出格式

输出一个整数，表示 Dr. Z 最多能吃的糖果数量。

## 样例

**输入：**

```text
5 5
0 2 3 2 2
```

**输出：**

```text
3
```
