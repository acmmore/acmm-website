# E. Test

- 时间限制：1 秒
- 内存限制：256 MB

## 题目描述

学生 A 参加了一场考试。考试有 `n` 道选择题，每题有 `m` 个选项，编号为 `1` 到 `m`。学生 A 的答题卡可以表示为数组 `a`，其中 `a_i` 是第 `i` 题所选的选项编号。答题卡必须满足 `a_i ≤ a_{i+1}`（`1 ≤ i < n`）。学生 A 会从所有满足条件的答题卡中等概率随机选择一张提交。

给定每道题的正确选项 `b_i`，求所有可能答题卡中，答对题目数量之和。答案对 `998244353` 取模。

模数 `M` 为素数时，若 `gcd(a, M) = 1`，则 `a` 在模 `M` 意义下的乘法逆元是满足 `a · x ≡ 1 (mod M)` 的整数 `x`。因此可在模意义下进行除法；一种求逆元的方法是 `x ≡ a^(M−2) (mod M)`。

## 输入格式

第一行包含两个正整数 `n, m`（`1 ≤ n, m ≤ 10^5`）。

第二行包含 `n` 个正整数，第 `i` 个整数 `b_i`（`1 ≤ b_i ≤ m`）表示第 `i` 题的正确答案。

## 输出格式

输出一个非负整数，表示所有可能答题卡答对题数之和对 `998244353` 取模后的结果。

## 样例

**输入：**

```text
2 3
1 3
```

**输出：**

```text
6
```

## 说明

用有序对 `(t_1, t_2)` 表示学生 A 的答题卡。`t_1` 是第一题所选选项，`t_2` 是第二题所选选项。满足条件的答题卡共有六张：`(1,1)`、`(1,2)`、`(1,3)`、`(2,2)`、`(2,3)`、`(3,3)`。它们分别答对 `1、1、2、0、1、1` 题，因此答案为 `1 + 1 + 2 + 0 + 1 + 1 = 6`。
