# A. the number of SYSU

- 时间限制：1 秒
- 内存限制：256 MB

## 题目描述

一年一度的中山大学程序设计竞赛又开始了。为了庆祝这一活动，你需要统计字符串 `SYSU` 在网格中出现的次数。

给定一个有 `n` 行、`m` 列的网格，每个格子中有一个大写字母。统计 `SYSU` 在网格中出现的次数，只考虑水平方向从左到右和竖直方向从上到下的匹配。不同的出现可以共享网格中的格子。

## 输入格式

第一行包含两个整数 `n, m`（`1 ≤ n, m ≤ 1000`）。

接下来 `n` 行，每行包含 `m` 个大写字母。第 `i` 行第 `j` 个字符表示网格第 `i` 行第 `j` 列的字母。

## 输出格式

输出一个整数，表示 `SYSU` 出现的次数。

## 样例 1

**输入：**

```text
5 5
SUSYS
UYUUS
SYSYS
YUUUS
SSSYY
```

**输出：**

```text
0
```

## 样例 2

**输入：**

```text
4 4
ASZJ
SYSU
SSAA
SUPJ
```

**输出：**

```text
2
```
